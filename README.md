## 🧭 What I do

I make software that runs anywhere — Mac, Windows, Linux and beyond. If a tool only exists on one platform, I want to port it. If a guide is confusing, I want to rewrite it into a *better* one.

- 🔁 Cross-platform ports and tools that break OS lock-in
- 🦀 Native desktop apps and developer tools
- 🏠 Offline-first, privacy-respecting tech
- 📚 Clear guides for things that are usually hard

👉 Browse my [repositories](https://github.com/A-Hackers-Guide?tab=repositories) to see what I'm building.
